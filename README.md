# Soheean High: Hallway Pass

미국 하이틴 드라마 속 고등학교 복도를 옆으로 걸으며 둘러보는 2D 포트폴리오입니다.
→ https://soheean1370.github.io/

## 조작법
- PC: `←` `→` 또는 `A` `D`로 이동, `Enter` / `Space`로 문·락커 열기. 물건을 클릭하면 그 앞까지 걸어가서 열어요.
- 모바일: 하단 ◀ ▶ 버튼으로 이동, `OPEN`으로 열기 (물건을 탭해도 돼요).
- 오른쪽 위 **Skip to Portfolio**: 게임 없이 전체 내용을 한 페이지로 보기 (`/?skip` 또는 `#portfolio`로 바로 열기).

## 복도 지도
입구(학생증) → 내 락커(FireGenerators) → 락커 101–104(다른 프로젝트) → 카페테리아 주크박스 → 졸업앨범실 → 교무실(이력서 PDF)

## 구조
- `index.html`: 복도 화면 + 전체 포트폴리오 내용 (JS가 없으면 포트폴리오만 보여요)
- `css/style.css`: 크림 / 세이지 / 더스티 핑크 / 버터 / 민트 팔레트, 필름 그레인, 햇살
- `js/main.js`: 이동, 카메라, 근처 물건 감지, 모달 (라이브러리 없음)
- `assets/resume.pdf`: 이력서
